# Getting help

- **Something is broken or missing**: search the
  [open issues](https://github.com/NecturaLabs/Canopy/issues) first, then start a
  [discussion](https://github.com/NecturaLabs/Canopy/discussions): issues are the maintainer's
  backlog, so only collaborators open them, and the maintainer files one from your report. Include Canopy's build number (About Canopy in the command palette, or
  `canopy --version`), your operating system, your git version (`git --version`) and the steps
  that show it.
- **A question about using Canopy**: [docs/features.md](docs/features.md) lists what Canopy does,
  [docs/keybindings.md](docs/keybindings.md) its shortcuts and the README its install and command
  line. If those do not answer it, ask in
  [Discussions](https://github.com/NecturaLabs/Canopy/discussions) (Q&A), where the answer helps
  the next person too. E-mail support@necturalabs.com only for something private.
- **A security problem**: never in a public issue. Follow [SECURITY.md](SECURITY.md).
- **Behaviour in project spaces**: see the [code of conduct](CODE_OF_CONDUCT.md).
