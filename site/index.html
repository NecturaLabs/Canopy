History as a graph.

Each line of history gets its own colour, and branches, remotes and tags are labelled on the commits they point to. Select a commit to see its files, line counts and diff.

Author pictures come from GitHub or GitLab; authors without one get their initials.

  • CtrlF or /Search by message, author or SHA
  • JKNext and previous commit
  • YCopy the commit's SHA
  • ShiftTTag the commit
  • OOpen it on GitHub or GitLab

Stage files, hunks or single lines.

The diff shows unified or side by side, with syntax colours. Each step from a changed file to a commit has a key.

  1. 2Open Changes
  2. JKMove through files
  3. SpaceStage or unstage
  4. CWrite the message
  5. CtrlEnterCommit
  • The Commit button says why it can't run yet.
  • Amend the last commit from the same view.
  • When git refuses, you see git's own message.

Conflicts, side by side.

The resolver shows your version and the incoming one together: keep either, both, or edit by hand. Continue and Abort stay in view until the merge, rebase or cherry-pick is done.

  • ][Next and previous conflict
  • HLTake current or incoming
  • BTake both
  • ZUndo the choice

Discarding, a hard reset, deleting a branch and force pushing ask first. A force push always uses --force-with-lease.

Pull and merge requests, in the app.

Read, review, check out and merge GitHub pull requests and GitLab merge requests, self-hosted GitLab included. With a token, every row shows its checks and reviews.

  • 3Open pull requests
  • CtrlShiftAApprove
  • CtrlShiftMMerge, after you confirm

The requests shown are Canopy's built-in demo data. A token is only ever sent to the host it belongs to.

Keyboard shortcuts and a command palette.

CtrlK opens the command palette, which lists every command and every branch to check out, and ? shows every shortcut. Lists take vim motions and single-key actions, the way lazygit does.

  • Super is never bound: it stays your window manager's.
  • Bare keys never fire while you are typing.
  • P pulls, ShiftP pushes, F fetches.

Three themes, one of your own, and high contrast.

Midnight is the default dark theme and Daylight the light one. Observatory has navy backgrounds and a periwinkle accent. High contrast works over any of them; switch it in Settings, the toolbar's theme menu or the command palette.

Start from Midnight or Daylight in Settings → Appearance, then pick an accent (a swatch or any hue, and how vivid it is) and a tint for backgrounds, lines and text.

Text and lines keep at least the base theme's contrast, and the status, graph, syntax and diff colours keep their hues.

Shown: accent hue 150, with a tint of 40 at the same hue.

What Canopy sends, and to whom.

It contacts

  • Your remotes, through your own git with your SSH and credential setup.
  • Your repository's GitHub or GitLab, for pull requests and author pictures, and the picture hosts they name.
  • GitHub, at most once a day, to check for a new build, which you can turn off. A new build is downloaded only when you choose Update.
  • NecturaLabs, through Sentry, for crash reports, only if you say yes. Your computer's name and home folder are removed first.

It has no

  • Telemetry or analytics.
  • Account or sign-in.
  • Server of its own between you and your code.

Canopy's own requests wait until you accept the terms and answer the crash-report question, and each has an off switch.

Install with one command

$ curl -fsSL https://canopy.necturalabs.com/install | sh

  • The address redirects to the installer script in the public NecturaLabs/app-updates repository on GitHub, so you can read it before you run it.
  • Installs for your user only, without sudo or administrator rights: into ~/.local/opt/canopy on Linux and %LOCALAPPDATA%\Programs\Canopy on Windows.
  • Checks the archive's SHA-256 against the published checksum and stops if they differ.
  • Run it again to upgrade. It leaves an uninstaller in the install folder, and uninstalling keeps your settings.
  • Canopy needs git 2.30 or newer on your PATH. The installer never installs it for you.
