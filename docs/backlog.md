# Backlog migrated to GitHub Issues

**Single source of truth:** [Canopy open GitHub Issues](https://github.com/NecturaLabs/Canopy/issues?q=is%3Aissue+is%3Aopen).

All **107 open backlog entries** were migrated on 8 October 2026. Each issue contains
the original description and its section (`Now`, `Next`, `Later`,
`Awaiting in-app verification (owner)`, or `Owner to-dos`) and order.

Read and update **GitHub Issues**, not this Markdown file. Create an issue for any newly
discovered work, track progress and test results in the issue, and close it only
after the acceptance criteria are verified. Keep tasks requiring live or owner
verification open. See [AGENTS.md](../AGENTS.md#workflow).

The [original pre-migration backlog](https://github.com/NecturaLabs/Canopy/blob/4e69c5fbc9461ab6a1c6ea9d4b976b23fb6368d0/docs/backlog.md)
